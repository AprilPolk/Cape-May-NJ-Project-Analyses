# Cape May NJ Project Analyses
R code and statistical analyses for my MPS project examining historical record span, 2026 resighting frequency, and visible human-interaction indicators in Tamanend's bottlenose dolphins of Cape May, New Jersey.

The script includes: 
1) Data preparation
3) Correlation analyses
4) Generalized Poisson models
5) Model diagnostics
6) Logistic regression models
7) Summary statistics
8) Figure generation
